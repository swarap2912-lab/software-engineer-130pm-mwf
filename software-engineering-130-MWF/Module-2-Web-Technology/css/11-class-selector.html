moon

The Moon is Earth's only natural satellite, orbiting at an average distance of about 384,400 km (238,900 miles) with a radius of 1,079.6 miles (about 1,737 km). It shines by reflecting sunlight and stays tidally locked to Earth so the same near side always faces us.
